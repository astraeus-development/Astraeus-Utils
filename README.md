# Astraeus-Utils
Run the html in your browser to help you fix bugs & code!

# How to run
1. Install a machine (Ollama recommended: https://ollama.com/)
   Ollama runs AI models locally — completely free, no internet needed after setup.
   - Install from ollama.com
   - Run: ollama pull llama3.2
   - Ollama starts automatically on port 11434

2. Everything is set up!
3. NOTE: IF YOU GET "ERROR: FAILED TO FETCH", RUN [ launchctl setenv OLLAMA_ORIGINS "*" ] in your terminal for MacOS (search google what the windows alternative is for it idk)

You can use alternatives to Ollama, such as LM studio, Openrouter, or Claude (using your own API credits)
