AI Backend Settings
Choose how Astraeus Utils connects to an AI model. Ollama and LM Studio are 100% free and run locally on your machine.
Ollama runs AI models locally — completely free, no internet needed after setup.

1. Install from ollama.com
2. Run: ollama pull llama3.2
3. Ollama starts automatically on port 11434
Other options: codellama, mistral, deepseek-coder, phi3, gemma2
LM Studio runs models locally with a GUI — free forever.

1. Download from lmstudio.ai
2. Download a model inside the app
3. Go to Local Server tab and click Start Server
Copy the model identifier shown in LM Studio's server tab
OpenRouter — free tier available with many models, no credit card required to start.

1. Sign up at openrouter.ai
2. Go to Keys and create an API key
3. Free models are marked with ":free"
Anthropic API — requires an API key with credits. New accounts get free trial credits.

1. Get a key at console.anthropic.com
2. Note: direct browser requests require serving from a local server (e.g. python -m http.server)
